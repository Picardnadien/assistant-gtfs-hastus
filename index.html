Création des codes de placeLes codes générés contiennent exactement 6 ou 8 caractères : lettres significatives du nom, puis zéros si le nom est trop court, sans ajout de X. Les codes existants ne sont pas modifiés et la saisie manuelle peut rester plus courte. Les codes dépassant la longueur choisie doivent être corrigés avant l’export.
« St » en début de nom est conservé pour Saint. Les lieux reconnus gardent leur type dans la description et un suffixe dans le code : station/gare STN, terminal/terminus TER, hub/pôle HUB, échangeur ECH, centre de transit CTR. Ces règles s’appliquent aux nouvelles propositions, sans renommer les places existantes.
